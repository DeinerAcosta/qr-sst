# Fotos de productos

Esta carpeta contiene **fotos reales de los productos químicos y gases**
para usar en la Escena 2 (presentación del producto) de cada video.

## Naming

Usá el **mismo ID** del producto en `quimicos/datos.js` o `gases-medicinales/datos.js`,
con extensión `.jpg` o `.png`:

```
20-diablo-rojo.jpg       (para producto id "20-diablo-rojo")
30-soda-caustica.jpg     (para producto id "30-soda-caustica")
oxigeno-medicinal.jpg    (para gas id "oxigeno-medicinal")
```

Así cualquier persona sabe inmediatamente a qué producto pertenece cada foto.

## Cómo conseguir cada foto

1. Buscá en Google Images: `<nombre del producto> + envase` o `+ producto`
2. Elegí una nítida, con fondo blanco si es posible
3. Click derecho → "Guardar imagen como…"
4. Renombrala con el ID del producto
5. Pegala en esta carpeta
