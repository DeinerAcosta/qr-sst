# EPP — Imágenes reales

Esta carpeta contiene **fotos reales de Equipos de Protección Personal**
para usar en los videos. Las imágenes deben tener fondo blanco o
transparente, en buena resolución (mínimo 800×800 px).

## Naming (cómo nombrar cada archivo)

| Archivo | Para qué se usa |
|---------|-----------------|
| `bata-blanca.png` o `.jpg` | Ropa de protección clínica |
| `gafas-seguridad.png` | Protección ocular |
| `guantes-quimicos.png` | Guantes resistentes a químicos |
| `guantes-nitrilo.png` | Guantes desechables nitrilo |
| `careta-facial.png` | Careta / protección facial completa |
| `mascarilla-n95.png` | Mascarilla respiratoria |
| `casco-azul.png` | Casco de seguridad |
| `botas-seguridad.png` | Calzado de seguridad |
| `delantal-impermeable.png` | Delantal contra salpicaduras |
| `chaleco-reflectivo.png` | Chaleco de alta visibilidad |
| `tapones-auditivos.png` | Protección auditiva |

## Cómo agregar una imagen nueva

1. Descargá la foto (Google Images → buscar "guantes nitrilo png fondo blanco")
2. Renombrala con el formato de arriba
3. Pegala en esta carpeta
4. Lista para usar en HeyGen
